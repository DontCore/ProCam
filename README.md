# ProCam (iOS)

Кастомное приложение камеры: повторяет привычный сценарий штатной камеры, но с полным контролем.

- **Фото и видео** — переключение режима снизу.
- **Все камеры** — задняя/фронтальная переключаются на лету (фронтальная пишет максимум 30 fps — ограничение железа SE 2020).
- **60 fps видео** — задняя камера SE (2020) умеет 1080p60 и 4K60; выбирается в верхней панели.
- **Пропорции 4:3 / 16:9 / 1:1**:
  - фото — кадрируется при съёмке из полного сенсорного кадра 4:3;
  - видео — записывается в нативных 16:9, после остановки автоматически кропится под выбранную пропорцию (для 16:9 — сразу сохраняется); прогресс виден как «Обработка видео…».
- **Горизонтальная съёмка** — поверни телефон набок: превью, ориентация записи и итоговый ролик становятся горизонтальными (не вертикальными).
- Всё сохраняется в системную медиатеку.

## Сборка без Mac

1. Залей папку в публичный репозиторий GitHub → **Actions** → «Build ProCam IPA» → скачай артефакт `ProCam-unsigned-ipa`.
2. Установка — [Sideloadly](https://sideloadly.io) + Apple ID (как у GiveSharing/TgWsProxy): 7 дней подписи на бесплатном аккаунте, Режим разработчика включён.

При первом запуске разрешите камеру, микрофон и добавление в медиатеку.
